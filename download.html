Verify the Android download

Check the APK against its published SHA-256 before you install it.

sha256sum -c SHA256SUMS.txt
CertUtil -hashfile VERAQIS-Archiver-Mobile-Android-2.10.0.apk SHA256
apksigner verify --print-certs VERAQIS-Archiver-Mobile-Android-2.10.0.apk

The signed APK is paired with a SHA-256 checksum in SHA256SUMS.txt. A checksum proves file integrity; it is not a publisher signature. The APK is additionally signed (schemes v2 and v3) with the VERAQIS Archiver Mobile certificate, subject CN=VERAQIS Archiver Mobile Local Build, certificate SHA-256 fd8106cbcd6529754a228f4acd4b4e4746331fc91e5c47439af1e518c7236cbe. That is a different certificate from the release key that signed Archiver Pro 1.8.0.

Why packages may be withheld

VERAQIS Recovery will return only as a fresh, signed, reviewed artifact. Withholding a package is a safety step, not a claim that a previous file was harmful.

Product source and development repositories are not distributed through this website.

Download questions

The current beta artifact state in plain language.

What can be downloaded today?

The current public-beta download set contains only the signed VERAQIS Archiver Mobile 2.10.0 APK. Verified ZIP recovery runs in VERAQIS Studio, in your browser, with nothing to install.

Are these production-signed releases?

The Android APK is signed (schemes v2 and v3) with the VERAQIS Archiver Mobile certificate, whose SHA-256 is published above. It is a different certificate from the release key that signed Archiver Pro 1.8.0. No desktop artifact is offered.

Is there a desktop or CLI download?

There is no CLI download. VERAQIS ships two things: the Android APK and VERAQIS Studio in the browser.

Are Android builds included here?

Yes. Download the signed VERAQIS Archiver Mobile APK directly from this page. It replaces Archiver Pro 1.8.0 as the Android download and installs as a separate app.
