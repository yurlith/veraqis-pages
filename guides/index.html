A test you can run on any tool

Feed it something genuinely unrecoverable — an encrypted archive without the password, or random bytes named .zip. A tool that reports success has told you what its other results are worth.

Before you run any repair tool

  1. Work on a copy. Repair tools that write in place can turn a recoverable file into an unrecoverable one. VERAQIS opens the original read-only and never writes to it.
  2. Check whether it is really damaged. Compare the size against the source, or re-download. A truncated download is the single most common cause and a fresh copy simply works.
  3. Check whether it is really that format. The magic number decides, not the extension. Files renamed to .zip are common.
  4. Check whether it is encrypted. An encrypted archive is not damaged and cannot be repaired into an open one. No legitimate tool bypasses that.
  5. Then diagnose, then decide. Knowing which entries are provably intact tells you whether recovery is worth attempting at all.
Be careful with online repair services. Uploading a damaged file sends its full contents to a third party — including anything private inside the archive. For a backup, an export or a work archive that is often the most sensitive data you have. Any tool worth using can analyse it locally.
