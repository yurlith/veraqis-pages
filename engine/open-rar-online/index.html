RAR in a browser tab, with nothing installed

The engine page includes UnRAR 7.23 by Alexander Roshal, compiled to WebAssembly (0.2 MB). It can list a RAR archive, test it — decompress every file and check every checksum without writing anything — and extract all files or the ones you pick. The archive is read from your disk and never uploaded.

Checked against all 29 reference archives of the VERAQIS Android app: every one extracts to its reference SHA-256. With encrypted-header fixtures, the right password opened, wrong passwords were refused every time, and three deliberately broken headers were refused even with the right password.

Open a RAR file online, without uploading it

  1. Open the full engine and add the .rar file — for a multi-volume set, add every part.
  2. Under RAR archives, open Open a RAR archive.
  3. Type the password only if the archive is encrypted.
  4. Press List to see the contents, Test to check every checksum, or Extract to download the files — all of them or only those you select.

Damaged RAR: verified recovery

For damaged archives the engine also has its own Verified RAR recovery method, labelled limited in its registry: it lists the verified RAR5 inventory and extracts stored (uncompressed) files exactly, with localisation of the archive’s recovery record. Recovery of compressed proprietary payload is not claimed. Run it under Recover contents → RAR archive.

Questions

How do I open a RAR file without installing anything?

Open the engine page in any current browser, add the .rar file and press List or Extract. UnRAR runs inside the page; the file is never uploaded.

Can it extract multi-volume RAR archives?

Yes. Add every volume of the set. If one is missing, the engine names it.

Can it open a password-protected RAR?

Only with the password you type. It does not guess, crack or store passwords.

How do I check whether a RAR is damaged?

Press Test: every file is decompressed and its checksum checked, without writing anything. Damaged files are reported as checksum failures.

Run it on your own file — free, on your device

The full engine opens the file read-only in this browser and writes results only as downloads. Nothing is uploaded, there is no account, and every function is free.
