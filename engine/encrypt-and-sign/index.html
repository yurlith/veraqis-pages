Encrypt a file without sending it anywhere

Online encryption tools usually mean uploading the very file you want to protect. Here the engine encrypts it inside your browser tab. Encrypt a file writes an AES-256-GCM container (.phx) using a password or a key file. GCM authenticates as well as encrypts: a wrong password or a changed byte gives no output at all, rather than garbage.

The functions

FunctionWhat it does
Encrypt a fileAES-256-GCM container (.phx) with a password or a key file.
Decrypt a .phx fileOpens a container made with Encrypt. A wrong password gives no output.
About an encrypted fileShows the original name, size, algorithm and date of a .phx container — without a password.

Check a signatureChecks a file against its .sig and the signer’s public key. One changed byte makes it fail.

Two things to know before you encrypt

There is no recovery

Without the password or key file, a .phx cannot be opened — by you, by VERAQIS or by anyone. Keep the key somewhere safe.

The name is not hidden

The container records the original file name, size, algorithm and date, and About an encrypted file shows them without a password. If the name itself is sensitive, rename the file before encrypting.

Sign a file so changes are detectable

  1. Open Sign a file. If you have no key, generate one: the page creates an Ed25519 key pair with your browser’s Web Crypto and offers the private key (.ed25519) and public key (.pub) as downloads.
  2. Keep the private key secret. Share the public key.
  3. Add the file and your private key, and press Run. Download the .sig.
  4. Anyone can check it with Check a signature: the file, its .sig and your .pub.

If a browser cannot create Ed25519 keys, the page says so; a 32-byte key file made elsewhere works instead.

Checksums versus signatures

A CRC-32 catches accidental damage but can be forged deliberately in an instant — we built CRC-32 collisions that pass gzip -t. A signature is the right tool when the question is “did anyone change this?”. To also rebuild a damaged file, pair it with repair data.

Questions

Can I encrypt a file online without uploading it?

Yes. Encrypt a file runs in your browser and gives you the .phx as a download.

What if I forget the password?

The file cannot be opened. There is no recovery or reset, by design.

Can VERAQIS decrypt a ZIP, RAR or PDF whose password I lost?

No. The engine never cracks, guesses or bypasses passwords. Archives open only with the password you type.

What does an Ed25519 signature prove?

That the file is byte-for-byte the one the key holder signed. One changed byte makes the check fail.
