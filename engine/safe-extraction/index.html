An archive can attack the machine that extracts it

A ZIP or TAR can carry entries named ../../.ssh/authorized_keys that escape the folder you extract into (“Zip Slip”), symlinks that point outside it, absolute or Windows drive and UNC paths, reserved device names, overlapping entries, or a few kilobytes that expand to terabytes (a zip bomb). Most extractors trust the archive. The engine scans it first.

Three functions

Is it safe to open?

A read-only safety scan: zip bombs, paths that escape the folder, links and other traps, reported before anything is extracted.

Look inside

The tree of an archive or document, with previews of entries, without extracting anything or opening it in another program.

Extract safe entries

Lists what can be extracted safely, lets you pick, and extracts only those. Traps are refused.

Check an archive before you extract it

  1. Open the full engine and add the archive.
  2. Run Is it safe to open? and read the verdict.
  3. Open Look inside to see the tree and preview entries.
  4. Open Extract safe entries, select what you need and download it.

What “safe” means here

“Safe” means structurally safe to extract: nothing escapes the folder, nothing explodes, nothing links elsewhere. The engine does not inspect file contents for malicious payloads — it is a structural safety inspector, not an antivirus. Learn the traps by playing Gatekeeper or Vera: Archive Guardian.

Questions

How do I check if a ZIP file is safe to open?

Run Is it safe to open?. It reports zip bombs, path traversal, links, absolute and reserved paths and overlapping entries without extracting anything.

What is Zip Slip?

An archive entry whose name contains ../ or an absolute path, so a naive extractor writes it outside the target folder — for example over a configuration file.

Does it scan for viruses?

No. It checks structure, not contents. A structurally safe archive can still contain a malicious program.

Can it extract a password-protected ZIP?

A traditional-ZIP archive, yes, with the password you type. Other encryption is refused.
