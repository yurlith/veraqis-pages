What "local" means here

  • The file is read with the browser File API and never leaves the page.
  • Analysis runs in a Web Worker in your browser; there is no upload endpoint for these tools to call.
  • Closing the tab discards everything the tool computed. Nothing persists on a server because nothing was sent to one.
