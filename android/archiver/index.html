What it does

Implemented and tested in the current build, not a roadmap.

  • Safety scan before open. A read-only scan classifies the archive — Safe, Suspicious, Blocked, Encrypted or Unsupported — before content is opened.
  • Safe listing. See what an archive contains without extracting it, with unsafe paths (traversal, absolute, reserved names) flagged rather than followed.
  • Safe extraction. Extraction is transactional and stays inside the destination you pick; entries failing a safety or integrity check are not written.
  • Writes only where you choose. Output goes to the folder you select through Android's own system picker.
  • SQLite row recovery, on-device. Recovers rows from a damaged SQLite database in an isolated process, states whether the current state is provably fresh, and can bound or prove a deleted row's original row ID from the database's own structure — never from its content. Details and screenshot.

"Safe" means structurally safe to extract. File contents are not inspected for malicious payloads — this is a structural safety inspector, not an antivirus.

Honest scope

  • Encrypted archives are detected and reported as encrypted. VERAQIS never decrypts, never cracks passwords and never bypasses access control.
  • Unsupported formats are reported honestly rather than guessed at.
  • Deep archive repair is not on mobile. For a damaged ZIP, 7z or RAR, the desktop's format-aware structural repair is where that work happens — start at verified ZIP recovery.
  • Passwords, when supplied, are handled as transient character data and are not written to models or logs.

Privacy and permissions

What the app can reach on your device, stated plainly.

  • No INTERNET permission is declared, so the app cannot send anything anywhere — this is enforced by a build gate, not a promise.
  • No account, no sign-in, no analytics, no advertising identifier.
  • Storage access is whatever you grant through the system picker, and nothing wider.
  • Backups are disabled (allowBackup="false") so archive contents are not swept into a cloud backup.
