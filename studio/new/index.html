What this analysis checks

  1. Reads the last 64 KiB and looks for the end-of-central-directory signature.
  2. Parses that record: entry count, index offset and size, comment length, trailing bytes.
  3. Detects ZIP64 structures and reports when sizes come from them.
  4. Reads the central directory, if it is present and reachable.
  5. Scans the whole file for local file headers, independently of the index — which is why it can describe an archive that will not open at all.
  6. Cross-checks each index record against the local header it points at.
  7. Checks that every declared data range lies inside the file, and flags overlaps.
  8. Flags duplicate names, absolute paths, .. traversal, control characters and NUL bytes.
  9. Recomputes the CRC-32 of every entry it can decode, and compares it to the stored value.

Full detail, including what is deliberately not attempted, is on the Studio overview.
