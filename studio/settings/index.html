Settings and local data

Every setting here is stored on this device only. There is no account and nothing is synchronised.

Analysis

Turning this off makes analysis faster and structural only. No entry is reported as verified without a recomputed checksum, so the verified count drops to zero.

Used to detect that a saved project has been re-opened against a different file. Full SHA-256 is exact but reads every byte, which takes time on large archives.

Measured: rendering 10,000 rows at once stalls the main thread for 487 ms in Firefox. Pages keep the interface responsive.

Local data

Off by default. With it off, an analysis exists only in this tab and disappears when you reload.

Checking storage…

Where this data lives

Settings are stored in this browser's local storage. Saved projects are stored in this browser's IndexedDB. Neither ever leaves the device, neither is synchronised, and there is no account to attach them to.

Delete all local VERAQIS data removes saved projects, settings and any cached application files this browser holds for VERAQIS. It cannot touch your archives — Studio never had a copy of them.
